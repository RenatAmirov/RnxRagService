# Rnx RAG

Локальная база знаний на ASP.NET Core и SQLite. Загрузите документы, задайте вопрос и откройте исходный фрагмент по номеру цитаты. Для PDF источник также содержит номер страницы.

## Запуск

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
dotnet run
```

Откройте [веб-интерфейс](http://127.0.0.1:5090). Можно загрузить PDF, TXT или Markdown и задать вопрос по всем файлам либо по одному из них. Кнопка «Добавить пример» загружает демонстрационный документ о VPN и подставляет вопрос.

Текстовые файлы должны быть в UTF-8. У PDF должен быть текстовый слой. Лимиты на один файл составляют 20 МиБ, 1 000 000 извлечённых символов и 1000 страниц PDF. Текст, метаданные и индекс хранятся в `data/rag.db`. Повторная загрузка файла с тем же содержимым возвращает существующий документ. Удаление документа удаляет его фрагменты из индекса. Сервис по умолчанию доступен на loopback и рассчитан на одного пользователя.

## Генерация и поиск по смыслу

В исходной конфигурации сервис находит фрагменты с помощью SQLite FTS5 и показывает подходящие цитаты. Для генерации и семантического поиска можно запустить локальную [Ollama](https://ollama.com/download) и задать модели перед запуском сервиса.

```powershell
ollama pull qwen2.5:3b
ollama pull bge-m3
$env:Rag__ChatModel = 'qwen2.5:3b'
$env:Rag__EmbeddingModel = 'bge-m3'
dotnet run
```

Обе настройки независимы. `Rag__OllamaUrl` задаёт адрес Ollama, по умолчанию `http://127.0.0.1:11434`. `Rag__DatabasePath` задаёт путь к базе, а `Rag__MinSimilarity` задаёт минимальное косинусное сходство для векторного поиска. Векторный поиск перебирает эмбеддинги выбранной базы или документа. Затем сервис объединяет результаты векторного и полнотекстового поиска.

Уже загруженные документы остаются доступны через полнотекстовый индекс. После подключения или смены модели эмбеддингов нажмите ↻ рядом с документом, чтобы добавить его в векторный поиск. Для пересчёта векторов при обновлении весов под тем же именем модели используйте API переиндексации. Если Ollama недоступна в момент вопроса, сервис возвращает доступные цитаты и сообщает о переходе на резервный режим. Если настроенная модель эмбеддингов недоступна при загрузке файла, сервис возвращает HTTP 503, и загрузку можно повторить.

## HTTP API

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/health` | Проверка доступности сервиса и просмотр настроенных моделей |
| `GET /api/documents` | Список документов |
| `POST /api/documents` | Загрузка одного файла в поле `file` формы multipart |
| `GET /api/documents/{id}` | Метаданные документа |
| `DELETE /api/documents/{id}` | Удаление документа |
| `POST /api/documents/{id}/reindex` | Пересчёт эмбеддингов документа |
| `GET /api/documents/{id}/chunks/{chunk}` | Полный текст фрагмента и страница PDF |
| `POST /api/ask` | Вопрос, ответ и источники |

```powershell
curl.exe -F "file=@wwwroot/example.md" http://127.0.0.1:5090/api/documents
$body = @{ question = 'Как подать заявку на доступ к VPN?'; topK = 5 } | ConvertTo-Json
Invoke-RestMethod http://127.0.0.1:5090/api/ask -Method Post -ContentType 'application/json; charset=utf-8' -Body $body
```

В запросе можно указать `documentId` и `topK` от 1 до 8. Ответ содержит `answer`, `mode` (`generated`, `extractive` или `no-answer`), `sources` и при необходимости `warning`. У каждого источника есть номер цитаты, имя документа, номер фрагмента, страница при наличии и URL полного текста. Каждый вопрос обрабатывается независимо.
